# ServiceNow Integrations Masterclass

**Build It The Right Way** · A free, hands-on masterclass for connecting ServiceNow to the systems your business depends on.

Learn REST and SOAP fundamentals, ServiceNow inbound and outbound integration patterns, Script Include and GlideAjax, source control, and integration tooling, all from real, hands-on video lessons.

> A free, open-source, video-driven course by [TechTalk with Bill](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA). Licensed under the MIT License.

## What is in this course

- **7 modules · 21 lessons**
- Every lesson has an embedded YouTube video, notes to reinforce it, and a done-when checklist
- All content built from real published videos, no theoretical placeholders

## Modules

- **Module 1 · Integration Foundations** — Understand what ServiceNow is at its core, how it handles requests, and how integrations fit into your enterprise stack.
- **Module 2 · API Fundamentals - REST vs SOAP** — Learn the difference between REST and SOAP, why REST won for most modern integrations, and where SOAP still fits.
- **Module 3 · RESTful API Design Background** — The RESTful API playlist. General API design and consumption background that gives you the language of integrations, even outside ServiceNow.
- **Module 4 · ServiceNow Integration Patterns** — Step-by-step ServiceNow integration tutorials for connecting the platform to the outside world.
- **Module 5 · Script Include and GlideAjax** — Server-side building blocks for reliable integrations. Script Includes and GlideAjax paired with REST.
- **Module 6 · Advanced Integration Patterns** — Resilience and decision-making. Circuit Breaker, when NOT to script, and where Integration Hub fits.
- **Module 7 · Source Control and Integration Tooling** — Version your integrations with GitHub, test APIs with Postman, and prototype without a live API using Service Virtualization.

## How to use this course

1. Start with **Getting Started** to set up your ServiceNow Personal Developer Instance
2. Work through the modules in order, they build on each other
3. Watch each video, then complete the Apply and Done-When sections
4. Ask questions in the comments on YouTube or subscribe for new lessons: [subscribe here](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA?sub_confirmation=1)
