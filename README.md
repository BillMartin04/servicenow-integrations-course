# ServiceNow Integrations Masterclass


### A Practical Course by TechTalk with Bill

Understanding a request and response is only part of integration work. You also need to know where the data comes from, how access is controlled, how failures are handled and how to verify the result.

This course organizes the [existing ServiceNow integration playlist](https://www.youtube.com/playlist?list=PLWMzEPW90q1aSU7CP-lKn8kqm9kB6pEBp) into the same learning format as the Flow Designer Masterclass. The ten playlist videos form the teaching sequence; Shorts and promotional previews are not used to fill course modules.

## Start here

Open [Getting Started](module-01-getting-started/README.md), or review the [full syllabus](SYLLABUS.md). The instructor introduction and PDI creation and configuration videos are reused from the existing courses.

## What you will learn

1. Understand the ServiceNow integration landscape.
2. Consume a REST API and inspect its request and response.
3. Understand API construction and security through the C# and ASP.NET examples.
4. Use the Postman example and connect a practice application to GitHub.
5. Follow the ServiceNow inbound and outbound integration demonstration.
6. Work through Script Include, GlideAjax and circuit breaker examples.
7. Verify the output of a programmatic data export.

## Who this course is for

This course is for ServiceNow administrators, developers and technical consultants learning integration concepts and implementation patterns. Platform navigation and basic scripting familiarity will help with the practical lessons.

## How to use this course

Each video lesson includes learning objectives, a practice exercise, evidence to keep, questions and navigation. The written introduction and prerequisites help you prepare before watching.

Use a PDI for the ServiceNow examples. C#, ASP.NET and Genesys are external examples from the source playlist, not additional ServiceNow products supplied by the course; follow the scope notes and identify any mock or design-only alternative in your evidence.

## Final assessment

Complete three short demonstrations with [published tasks, rubrics and evidence checklists](module-final-exam/README.md). The assessments total 100 points, allocated as 33, 33 and 34.

Everyone can use the exercises for practice. Personal review and a course Certificate of Completion are benefits for active Exam Navigator members or higher tiers, matching the Flow Designer course; this is not an official ServiceNow certification.
