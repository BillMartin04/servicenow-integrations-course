# ServiceNow Integrations Masterclass

### A Practical Course by TechTalk with Bill

An integration can return a response without solving the business problem. This course gives you a structured way to understand the request, inspect the data, choose an approach and demonstrate what actually works.

Follow the same learning format as the Flow Designer Masterclass: set up your lab, work through the topic modules, retain practice evidence, and finish with three short assessment demonstrations. There are **26 lesson pages across 8 modules**, followed by the final assessment section.

## Start here

Read the [full syllabus](SYLLABUS.md), then open [Getting Started](module-01-getting-started/README.md). The instructor introduction and PDI creation and configuration videos are reused from the existing courses.

The course uses **24 distinct existing videos**: 21 integration and tooling videos, plus three shared setup and instructor videos. The foundation video is also reused on the orientation page, and the prerequisites page is a written checklist. There is no additional course tour video.

## What you will learn

1. Prepare a PDI and safe integration practice environment.
2. Describe platform requests and compare REST and SOAP.
3. Inspect API contracts, requests, responses and access decisions.
4. Practice ServiceNow integration and data export patterns.
5. Work with Script Includes and GlideAjax.
6. Examine circuit breaker behavior and decide when not to script.
7. Use source control and integration testing tools.
8. Demonstrate your results against published assessment criteria.

## Who this course is for

This course is for ServiceNow administrators, developers and technical consultants who want a structured integration learning path. Familiarity with platform navigation and basic scripting will help with the practical lessons.

## How to use this course

Complete the modules in order. Each topic lesson has an existing video, learning objectives, a practice exercise, questions and navigation to the next lesson.

Use a PDI for the ServiceNow labs. C#, ASP.NET, Genesys and service virtualization lessons are clearly labelled as background or external tooling examples; they are not all PDI labs. The Integration Hub video is a short preview, not a complete implementation course.

## Final assessment

The [final assessment](module-final-exam/README.md) contains three video demonstrations scored at 33, 33 and 34 points, for a total of 100. Anyone can use the published tasks and rubrics for practice.

Personal review and a course Certificate of Completion are benefits for active Exam Navigator members or higher tiers, matching the Flow Designer course. This is an independent course completion assessment, not an official ServiceNow certification.

See the [submission guide](module-final-exam/submission-guide.md) for the current submission status before preparing a review request.
