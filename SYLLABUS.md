# Syllabus: ServiceNow Integrations Masterclass

## Source and scope

The integration teaching content comes exclusively from the [existing ten video playlist](https://www.youtube.com/playlist?list=PLWMzEPW90q1aSU7CP-lKn8kqm9kB6pEBp). No Shorts, teasers or unrelated videos have been added as integration lessons.

The instructor introduction and PDI creation and configuration add three shared videos. The course introduction and prerequisites are written pages, giving 15 lesson pages, 13 distinct videos and 5 learning modules, followed by the final assessment section.

The overview video is moved to the start of the topic lessons. The remaining playlist videos retain their relative order; the original playlist position is shown below for traceability.

## Course structure

| Module | Topic | Lesson pages |
|---|---|---|
| 1 | Getting Started and Your Lab Environment | 5 |
| 2 | Integration Overview and API Foundations | 4 |
| 3 | API Testing and Source Control | 2 |
| 4 | Building ServiceNow Integrations | 3 |
| 5 | Programmatic Data Export | 1 |
