# Exam 1 — REST API Basics and an Outbound Call

**Quick answer:** Record a single video of **5 minutes maximum** demonstrating the tasks below in your own ServiceNow Personal Developer Instance (PDI), narrating as you go. This exam covers **REST fundamentals, outbound integrations** and is worth **33 points**.

{% hint style="warning" %}
**Members-only review.** Your video is only graded if you are an active **Exam Navigator** member (or any higher tier) of [TechTalk with Bill](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA/join). Include your membership email/handle when you submit.
{% endhint %}

## The scenario

Prove you understand REST and can build a real outbound REST call from ServiceNow to a public API.

## What you must demonstrate in your video

Complete and narrate each of the following:

1. Explain briefly what REST is and how it differs from SOAP (30 seconds).
2. Build an **outbound REST message** to a public API (for example, a public weather or joke API).
3. Configure the HTTP method, endpoint, and any required headers.
4. Test the message from the UI and show the response.
5. Call the same REST message from a background script or Fix script and show the parsed result.

{% hint style="info" %}
**Time limit: 5 minutes.** Plan your steps before you hit record. Part of the skill is doing this efficiently — just like a real practitioner under deadline.
{% endhint %}

## Grading rubric (33 points)

Each criterion is scored at one of three levels so you know **exactly what you must prove on screen** to earn the points. Your instructor circles the level reached and returns written feedback.

| Criterion | ✅ Full credit — *proof required* | 🟡 Partial credit | ❌ No credit |
|-----------|-----------------------------------|-------------------|--------------|
| **REST understanding** | **7 pts** — Correct, concise REST vs. SOAP explanation. | **3 pts** — Explanation partially correct. | **0 pts** — No or wrong explanation. |
| **Outbound REST message** | **7 pts** — Configured correctly with method, endpoint, headers. | **3 pts** — Message exists but missing config detail. | **0 pts** — No REST message. |
| **UI test** | **7 pts** — Test succeeds and response is shown. | **3 pts** — Test runs but response not shown or fails. | **0 pts** — Test not run. |
| **Scripted call** | **6 pts** — Script calls REST message and parses response. | **3 pts** — Script calls but does not parse. | **0 pts** — No script call. |
| **Output evidence** | **6 pts** — Parsed values shown clearly on screen. | **3 pts** — Raw response shown but not parsed. | **0 pts** — No output shown. |
| **Total** | | | **/ 33** |

### Evidence checklist (what the grader looks for)

Your video passes most easily when every item below is visibly true on screen:

- [ ] Concise REST vs. SOAP explanation.
- [ ] Outbound REST Message exists with correct HTTP method + endpoint.
- [ ] Test result is shown in the UI.
- [ ] Script invokes the REST message and parses the response.
- [ ] Parsed data is displayed on screen.
