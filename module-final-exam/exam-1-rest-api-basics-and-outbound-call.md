# Exam 1: API Contracts, Security and Testing

**Quick answer:** Prepare and test your work, then record a narrated demonstration of no more than five minutes. This assessment covers Modules 2 and 3 and contributes 33 points to the 100 point course total.

{% hint style="warning" %}
Personal review is for active [Exam Navigator members or higher tiers](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA/join). Everyone can use the published tasks and rubrics for practice.
{% endhint %}

## The scenario

Prepare a fictional supplier API interaction using the API design and Postman lessons. If you do not have Genesys access, use a controlled mock and clearly label it.

## What you must demonstrate in your video

1. Show one example request and expected response from your API consumption practice.
2. Show the method, endpoint, applicable headers and body without exposing secrets.
3. Run the authorized request or mock and verify one returned value against the expected result.
4. Use the ASP.NET lesson to distinguish authentication from authorization, noting which configuration belongs to that example.
5. Use an annotated excerpt from the C# lesson or your own local reproduction to explain request handling and data retrieval.

Build before recording. Use synthetic data and your own authorized lab, and keep passwords, access tokens and client secrets out of recordings.
