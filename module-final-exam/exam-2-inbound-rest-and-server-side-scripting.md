# Exam 2: Inbound, Outbound and Client Server Integration

**Quick answer:** Prepare and test your work, then record a narrated demonstration of no more than five minutes. This assessment covers Modules 4 and contributes 33 points to the 100 point course total.

{% hint style="warning" %}
Personal review is for active [Exam Navigator members or higher tiers](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA/join). Everyone can use the published tasks and rubrics for practice.
{% endhint %}

## The scenario

Demonstrate the ServiceNow integration and GlideAjax patterns from Lessons 4.1 and 4.2. Use the inbound and outbound techniques shown in the videos; a new Scripted REST API is not required.

## What you must demonstrate in your video

1. Show a successful outbound request using the lesson's pattern and an authorized test endpoint.
2. Demonstrate the inbound example using synthetic records and explain which system is consuming ServiceNow data.
3. Show the Script Include used by your integration and identify its input and output.
4. Show the client request and the corresponding result returned through the demonstrated GlideAjax pattern.
5. Show a controlled invalid or unavailable response and explain what the client receives.

Build before recording. Use synthetic data and your own authorized lab, and keep passwords, access tokens and client secrets out of recordings.
