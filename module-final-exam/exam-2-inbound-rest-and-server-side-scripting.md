# Exam 2: Data Export, Script Includes and GlideAjax

**Quick answer:** Prepare and test your work, then record a narrated demonstration of no more than five minutes. This assessment covers Modules 5, 6 and contributes 33 points to the 100 point course total.

{% hint style="warning" %}
Personal review is for active [Exam Navigator members or higher tiers](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA/join). The tasks and rubrics are available to everyone for practice; check the submission guide for intake availability.
{% endhint %}

## The scenario

Your practice application needs to retrieve and present a small set of synthetic data. Use the export and client/server patterns already practised in Modules 5 and 6; creating a new Scripted REST API is not required.

## What you must demonstrate in your video

1. Show the synthetic records, selected fields and filter used in your export exercise.
2. Compare the manual and programmatic export exercises and explain any difference.
3. Show your Script Include, its input/output contract and a test result.
4. Demonstrate the GlideAjax interaction from Lesson 6.2 and show the result returned to the client.
5. Show how your example handles empty or invalid input, with secrets and private data excluded.

Build before recording. Use only your own lab, synthetic data and authorized endpoints; never show passwords, access tokens or client secrets.

## Grading rubric (33 points)

Select full, partial or no credit for each criterion. Add the awarded points and retain the evidence used to justify the score.

| Criterion | Full credit | Partial credit | No credit |
|---|---|---|---|
| Dataset and scope | 7: Dataset, fields and filter are explicit. | 3: Dataset shown but its selection is unclear. | 0: No relevant evidence. |
| Export verification | 7: Both results are reconciled against the selected data. | 3: Only one result is shown or differences are unexplained. | 0: No relevant evidence. |
| Reusable server logic | 7: The method and a correct result are demonstrated. | 3: The method exists but testing or the contract is incomplete. | 0: No relevant evidence. |
| Client/server interaction | 6: The client request and returned result are visibly connected. | 3: The call is shown without a clear returned result. | 0: No relevant evidence. |
| Invalid input and safety | 6: A controlled invalid case is demonstrated safely. | 3: The case is described but not tested. | 0: No relevant evidence. |
| Total possible | 33 | | |

This exam contributes 33 points. The three assessments are worth 33, 33 and 34 points, totalling 100.
