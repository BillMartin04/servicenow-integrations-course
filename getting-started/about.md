# About This Course

**ServiceNow Integrations Masterclass** is a free, hands-on masterclass from [TechTalk with Bill](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA).

## What you will learn

Learn REST and SOAP fundamentals, ServiceNow inbound and outbound integration patterns, Script Include and GlideAjax, source control, and integration tooling, all from real, hands-on video lessons.

## Course structure

- **7 modules · 21 lessons**
- Every lesson has an embedded video, reading notes, and a done-when checklist
- Built only from real, published videos on the TechTalk with Bill channel

## Prerequisites

- A ServiceNow Personal Developer Instance (free from [developer.servicenow.com](https://developer.servicenow.com/))
- Willingness to reproduce each exercise in your own instance

## How to use this course

1. Set up your instance using the Getting Started pages
2. Work through the modules in order
3. For each lesson: **Watch → Read → Apply → Done When**
4. Subscribe to the channel for updates: [YouTube](https://www.youtube.com/channel/UCMf7pje1x5iZkkEF-Y3PLSA?sub_confirmation=1)
