## Overview

ServiceNow and GitHub lab. Use your own practice application and repository, not a customer repository.

Watch the existing lesson first, then use the practice below to check your understanding. The practice is a course exercise, not a transcript of the video.

### Practice exercise

Use a disposable scoped application and a repository you own. Follow the connection workflow, make one harmless application change, and capture the resulting commit without showing credentials.

### Evidence to keep

A repository history entry linked to the application change.
